# Scientific frontend re-audit — Phase A

Date: 12 October 2026. Baseline: 59804867406a95873f9593c205fe6dccf6f9fe12 on main (includes the footer correction after 7400e6e). Scope: public tracked sources and local frontend only. Previous audit/validation reports remain historical records, not current acceptance evidence. No private sealed tasks, salt or operational configuration was inspected.

## Inventory and method

Read README, architecture documents, all fourteen final reports and their public structured summaries, the deep/robust/active/certificate preregistrations and sealed-set policy. Inspected implementation entry points, associated tests, benchmark modules, Makefile targets and scientific history. Core code establishes existence and scope; reports establish experimental claims; tests establish checks, not confirmation of a scientific hypothesis. Existing data-backed panels were inspected against their JSON loaders. No research campaign was rerun.

- Symbolic execution: world/entities/relations, transformations, invariants, algebra, conditional TRUE/FALSE/UNKNOWN, planner, command parser and predefined physics.
- Adaptive mechanisms: model state, structural learning, dynamic/plastic components, lifelong and continuum benchmarks/certificates.
- Language/evidence: grounded/language/discourse experiments, EvidenceGraph, source reliability, entitlement, temporal dynamics, associated benchmark modules.
- Measurement: LatentWorldState, Observable, ReferenceFrame, MeasurementContext, operator/distribution/outcome, compatible states and belief.
- Reconstruction: robust inference and measurement-aware search; candidate generation, primitive discovery, fitting, objectives, partial observations, fragments/types, boundary ownership, composition classes, end-to-end, latent sets and high precision.
- Public data: seventeen summaries already used by the frontend (fourteen milestones and three historical panels). Derived test scale is static declarations with source fingerprints, not a current research-suite execution count.
- Reproduction: Makefile local test/report targets; partition/seed/budget/precision requirements; historical consumed sealed evaluation versus retired deep v1 and private live deep v2.
- No .github/workflows directory exists; do not invent a CI passing status. Public workflow is documented through Makefile and protocols. Cloud command definitions are read as historical tooling, never executed.

## Findings requiring correction

1. All fourteen milestones are reachable, but most describe the experiment only as a report link. Their architecture, actual comparison, limits and refuted hypotheses need local explanations.
2. Objective-alignment milestone incorrectly borrows the later high-precision joint cell-floor conclusion. Its own report says none of six tested objectives is aligned on already-good candidates. Correct the attribution and retain the later result with its own source.
3. The validated-optimizer badge is an editorial synthesis, not its literal report verdict. The report's predefined guardrail criterion is met; no-op still outperforms fitting on exact starting parameters. Make that positive/negative distinction explicit.
4. Generation and primitive discovery are post-hoc diagnostics, not confirmatory results. Their early findings must remain historical; later exact-atom composition supersedes their downstream limits without solving discovery.
5. The bottleneck flow omits fragment extraction and type inference, and combines validation/reconstruction. The measurement flow omits explicit observable and reference frame.
6. No source-backed report hypothesis tables are exposed for earlier milestones. Native disclosure can reveal them without enlarging the homepage or inventing a global score.
7. There is no human participant comprehension study. The 30-second/5-minute/researcher assessments must be editorial walkthroughs with explicit limits, not reported user-test success.
8. LinkedIn is now confirmed and the self-domain footer shortcut removed; earlier audit notes about missing LinkedIn are historical, not current blockers.

## Proposed information architecture and implementation decision

Retain the existing five top-level sections, all routes, identity/palette and English default with browser detection plus saved selection. Home remains one definition and a current-status entry. Research programme gets bilingual architecture/experiment/limit explanations inside existing native milestone disclosures, local Makefile test/report pointers, and nested canonical English report tables/bullets. Source reports remain the scientific truth; no metric is recopied into editorial templates. Exact-atom and high-precision evidence pages retain their detailed charts. Architecture map gains missing observable/frame and discovery steps; four research families stay hierarchical.

Use the already informative accept/reject transition; no decorative animation or new dependency is justified. Add report/table provenance tests and actual browser checks for keyboard disclosure, all social links, and diagram stages. Re-run complete frontend/browser checks, container packaging/rendering, public GitHub source targets and diff/privacy checks. No production operation.

This document completes Phase A before frontend modifications for this mission. Phase B begins only after this record is written.
